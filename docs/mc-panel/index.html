MC Panel

An app to run a group of friends' Minecraft server from your phone.

Year
2026
Context
Personal project
Role
Product design and development

Our group's Minecraft server runs on my PC, and to play you had to message me to turn it on. MC Panel solves that: it shows whether the server is online and who is connected, lets players request a start with one button, notifies my phone to approve it, and adds chat, events and a remote console.

The design

One main action per screen: the switch in the middle. The in-between states (starting, stopping) live on the server, so every device sees the same thing, no matter where the command came from. The admin panel is an index of nine sections with descriptions, instead of a row of tabs you had to swipe sideways.

How it's built

React Native with Expo, a single codebase for iOS, Android and web, and a Node.js API running on the PC. Status comes from the same protocol the game's server list uses, with no plugins or mods. Shutdown goes through RCON so the world saves cleanly, and the scripts that can run are whitelisted.
