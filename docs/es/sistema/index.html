SISTEMA

Mi identidad personal en un sitio web: la trayectoria entre el código y el diseño.

Año
2026
Contexto
Proyecto final de 5.º semestre, UDE
Rol
Concepto, diseño y desarrollo

SISTEMA es un manifiesto infográfico. La pregunta era cómo mostrar una trayectoria que no va en línea recta (programación, edición, diseño) sin pedir disculpas por ella. La respuesta fue tratarla como un sistema: partes que solas no dicen nada y que juntas producen un sentido que ninguna tenía por separado.

Abrir el sitio ↗

La decisión

Un solo verde de terminal sobre negro, de principio a fin. Llegué a implementar un color para el código y otro para el diseño, con una transición entre los dos, y lo saqué: dos colores dicen que hay dos cosas que se equilibran. El proyecto dice que es una sola, vista desde dos ángulos.

  • Verde consola#00FF41
  • Fondo#060807
  • Blanco · texto#F0EDE8

Elementos

La navegación es una esfera que funciona como un grafo, tomado de Dijkstra. El histograma de herramientas es radial porque una línea de base arma un ranking, y acá no hay una herramienta mejor que otra. La geometría no está dibujada: la construye JavaScript a partir de los datos.

El código genera la forma; el diseño la vuelve legible.

Tipografía

La pieza cambia de temperatura cuando deja de mostrar datos y habla en primera persona: Space Mono para la estructura, Bebas Neue para anclar cada zona y DM Serif Display para la voz propia.
